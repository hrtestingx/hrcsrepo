## 🚀 Hızlı Kurulum

CloudStream 3 uygulamasına depoyu eklemek için aşağıdaki adımları takip edebilirsiniz:

1. **CloudStream** uygulamasını açın.
2. Sağ alttan **Ayarlar** (Settings) ➔ **Uzantılar** (Extensions) sekmesine gidin.
3. **Depo Ekle** (Add Repository) butonuna dokunun.
4. Karşınıza çıkan alana **Depo Adı** ve aşağıdaki kısa kodlardan birini yazıp kaydedin:

### 📋 Kurulum Kodları

| Kısa Kod | Durum | Açıklama |
| :--- | :---: | :--- |
| **`hrcsrepo`** | 🟢 **Önerilen** | Doğrudan GitHub CDN üzerinden hızlı indirme |
| **`hrcs`** | 🟡 **Alternatif** | Bazı ISS'lerde VPN veya DNS değişikliği gerekebilir |

**Veya doğrudan depo bağlantısı:**
```text
https://raw.githubusercontent.com/hrtestingx/hrcsrepo/master/repo.json
```

> [!TIP]
> Depoyu ekledikten sonra **Ayarlar ➔ Uzantılar** menüsünde **hrcsrepo** başlığı altında listelenen eklentilerden dilediklerinizi tek dokunuşla kurabilirsiniz.

## ❓ Sıkça Sorulan Sorular (S.S.S.)

<details>
<summary><b>1. "Bağlantı bulunamadı" veya "Yüklenemedi" hatası alıyorum, ne yapmalıyım?</b></summary>
<br/>
Bazı servis sağlayıcıları Türkiye'deki standart DNS adreslerinde engelli olabilir. Cihazınızda <b>Cloudflare DNS (1.1.1.1)</b> veya <b>Google DNS (8.8.8.8)</b> kullanmanız ya da güvenli bir VPN açmanız bu sorunu çözecektir. Ayrıca eklenti ayarlarından sağlayıcının güncel domain adresini değiştirebilirsiniz.
</details>

<details>
<summary><b>2. Eklentileri nasıl güncellerim?</b></summary>
<br/>
Depo adresimiz CloudStream'e eklendikten sonra yeni bir sürüm çıktığında CloudStream bunu otomatik olarak algılar. <b>Ayarlar ➔ Uzantılar</b> sekmesine gidip üstteki yenileme simgesine basarak veya <i>"Güncelle"</i> butonuna tıklayarak en son sürüme geçebilirsiniz.
</details>

<details>
<summary><b>3. Kaynak ayarlarını nasıl değiştirebilirim?</b></summary>
<br/>
CloudStream içinde <b>Ayarlar ➔ Uzantılar ➔ Eklenti Adı (örn: HR Anime)</b> üzerine gelin ve kumandanızın orta (OK) tuşuna basarak eklenti ayarlarına girin. Açılan menüden kaynakları açıp kapatabilir veya yeni domain girebilirsiniz.
</details>
